## できること

画像をボードにドロップして、各段にドラッグします。できあがったら PNG で保存するか、そのまま投稿にコピーできます。

- 画像はきれいに整列します。整列をオフにすれば好きな場所に置けます。
- 画像の下に短いメモを書いたり、段の名前や色を変えたりできます。
- フォント、色、サイズ、枠線、角の丸みまで、見た目をまるごと変更可能。すぐ使えるスタイルも4種類。

## はじめかた

1. <a href="https://openrootdev.github.io/tierlist-studio/">openrootdev.github.io/tierlist-studio</a> を開くだけ。インストールは不要です。
2. または <a href="https://github.com/OpenRootdev/tierlist-studio/releases/latest/download/tierlist-studio.zip">tierlist-studio.zip</a> をダウンロードして展開し、<code>index.html</code> を開きます。
3. 画像をドロップして段に並べ、<b>Export PNG</b> をクリック。

```bash
git clone --depth 1 https://github.com/OpenRootdev/tierlist-studio
```

## 必要なもの

- 最新のブラウザ（Chrome、Edge、Firefox、Safari）。
- フォントと画像の書き出しのため、開くときにインターネット接続。
- あなたの画像。パソコンの中に残り、アップロードされることはありません。
