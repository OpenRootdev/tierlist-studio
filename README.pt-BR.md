## O que faz

Solte suas imagens no quadro e arraste para os níveis. Quando ficar bom, salve como PNG ou copie direto para um post.

- Os itens se encaixam certinho, ou você desliga o encaixe e coloca onde quiser.
- Escreva uma nota curta embaixo de qualquer imagem, renomeie os níveis e escolha as cores.
- Mude o visual inteiro: fontes, cores, tamanhos, bordas e cantos arredondados, com quatro estilos prontos.

## Começar

1. Abra <a href="https://openrootdev.github.io/tierlist-studio/">openrootdev.github.io/tierlist-studio</a>. Não precisa instalar nada.
2. Ou baixe <a href="https://github.com/OpenRootdev/tierlist-studio/releases/latest/download/tierlist-studio.zip">tierlist-studio.zip</a>, descompacte e abra o <code>index.html</code>.
3. Solte suas imagens, arraste para os níveis e clique em <b>Export PNG</b>.

```bash
git clone --depth 1 https://github.com/OpenRootdev/tierlist-studio
```

## O que você precisa

- Um navegador atual: Chrome, Edge, Firefox ou Safari.
- Conexão com a internet ao abrir, para as fontes e a exportação da imagem.
- Suas próprias imagens. Elas ficam no seu computador e nunca são enviadas.
