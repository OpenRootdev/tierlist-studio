## Qué hace

Suelta tus imágenes en el tablero y arrástralas a los niveles. Cuando quede bien, guárdalo como PNG o cópialo directamente en un post.

- Los elementos se colocan solos en su sitio, o puedes desactivar el ajuste y ponerlos donde quieras.
- Escribe una nota breve debajo de cualquier imagen, cambia el nombre de los niveles y elige sus colores.
- Cambia todo el aspecto: fuentes, colores, tamaños, bordes y esquinas redondeadas, con cuatro estilos listos.

## Primeros pasos

1. Abre <a href="https://openrootdev.github.io/tierlist-studio/">openrootdev.github.io/tierlist-studio</a>. No hay que instalar nada.
2. O descarga <a href="https://github.com/OpenRootdev/tierlist-studio/releases/latest/download/tierlist-studio.zip">tierlist-studio.zip</a>, descomprímelo y abre <code>index.html</code>.
3. Suelta tus imágenes, arrástralas a los niveles y pulsa <b>Export PNG</b>.

```bash
git clone --depth 1 https://github.com/OpenRootdev/tierlist-studio
```

## Qué necesitas

- Un navegador actual: Chrome, Edge, Firefox o Safari.
- Conexión a internet al abrirlo, para las fuentes y para exportar la imagen.
- Tus propias imágenes. Se quedan en tu ordenador y nunca se suben.
