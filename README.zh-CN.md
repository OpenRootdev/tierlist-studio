## 它能做什么

把图片拖到面板上，再拖进各个档位。满意之后，存成 PNG，或者直接复制到帖子里。

- 图片会自动整齐排好；关掉对齐后，也可以放在任何位置。
- 在任意图片下写一句短评，给档位改名、换颜色。
- 整体外观都能改：字体、颜色、大小、边框和圆角，还有四种现成风格。

## 快速开始

1. 打开 <a href="https://openrootdev.github.io/tierlist-studio/">openrootdev.github.io/tierlist-studio</a>，无需安装。
2. 或者下载 <a href="https://github.com/OpenRootdev/tierlist-studio/releases/latest/download/tierlist-studio.zip">tierlist-studio.zip</a>，解压后打开 <code>index.html</code>。
3. 拖入图片，把它们放进各档，然后点击 <b>Export PNG</b>。

```bash
git clone --depth 1 https://github.com/OpenRootdev/tierlist-studio
```

## 你需要什么

- 较新的浏览器：Chrome、Edge、Firefox 或 Safari。
- 打开时需要联网，用于加载字体和导出图片。
- 你自己的图片。它们只留在你的电脑上，不会被上传。
