## Was es macht

Zieh deine Bilder aufs Board und ordne sie den Stufen zu. Wenn alles passt, speicherst du es als PNG oder kopierst es direkt in einen Post.

- Bilder rasten ordentlich ein, oder du schaltest das Einrasten aus und legst sie frei irgendwo hin.
- Schreib eine kurze Notiz unter jedes Bild, benenne Stufen um und wähle ihre Farben.
- Ändere den ganzen Look: Schriften, Farben, Größen, Rahmen und runde Ecken, mit vier fertigen Stilen.

## Loslegen

1. Öffne <a href="https://openrootdev.github.io/tierlist-studio/">openrootdev.github.io/tierlist-studio</a>. Du musst nichts installieren.
2. Oder lade <a href="https://github.com/OpenRootdev/tierlist-studio/releases/latest/download/tierlist-studio.zip">tierlist-studio.zip</a> herunter, entpacke es und öffne <code>index.html</code>.
3. Zieh deine Bilder hinein, ordne sie den Stufen zu und klick auf <b>Export PNG</b>.

```bash
git clone --depth 1 https://github.com/OpenRootdev/tierlist-studio
```

## Was du brauchst

- Einen aktuellen Browser: Chrome, Edge, Firefox oder Safari.
- Eine Internetverbindung beim Öffnen, für die Schriften und den Bild-Export.
- Deine eigenen Bilder. Sie bleiben auf deinem Computer und werden nie hochgeladen.
