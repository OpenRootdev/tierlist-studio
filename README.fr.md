## Ce que ça fait

Déposez vos images sur le tableau et glissez-les dans les niveaux. Quand c'est prêt, enregistrez-le en PNG ou copiez-le directement dans un post.

- Les éléments se rangent tout seuls, ou vous désactivez l'alignement pour les poser où vous voulez.
- Écrivez une courte note sous n'importe quelle image, renommez les niveaux et choisissez leurs couleurs.
- Changez tout le style : polices, couleurs, tailles, bordures et coins arrondis, avec quatre styles prêts à l'emploi.

## Démarrer

1. Ouvrez <a href="https://openrootdev.github.io/tierlist-studio/">openrootdev.github.io/tierlist-studio</a>. Rien à installer.
2. Ou téléchargez <a href="https://github.com/OpenRootdev/tierlist-studio/releases/latest/download/tierlist-studio.zip">tierlist-studio.zip</a>, décompressez-le et ouvrez <code>index.html</code>.
3. Déposez vos images, glissez-les dans les niveaux, puis cliquez sur <b>Export PNG</b>.

```bash
git clone --depth 1 https://github.com/OpenRootdev/tierlist-studio
```

## Ce qu'il vous faut

- Un navigateur récent : Chrome, Edge, Firefox ou Safari.
- Une connexion internet à l'ouverture, pour les polices et l'export d'image.
- Vos propres images. Elles restent sur votre ordinateur et ne sont jamais envoyées.
